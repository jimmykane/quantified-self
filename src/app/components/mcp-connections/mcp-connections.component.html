Authorizing on Android

Desktop setup is the most reliable option. Android may send the final return address to the installed ChatGPT app. If the app opens but does not continue setup, no active connection is created. Complete the flow in ChatGPT on the web from a desktop, or temporarily turn off Open supported links for ChatGPT under Android's app settings, retry in the browser, and restore the setting afterward.

During authorization, you can approve any combination of these access categories:

  • query_stats{{ scopeLabels['metrics:read'] }}
  • monitor_weight{{ scopeLabels['measurements:read'] }}
  • directions_run{{ scopeLabels['activity-details:read'] }}
  • location_on{{ scopeLabels['activity-location:read'] }}
  • bedtime{{ scopeLabels['sleep:read'] }}
  • route{{ scopeLabels['routes:read'] }}
  • map{{ scopeLabels['route-location:read'] }}

Activity details include non-location summaries, laps, jumps, swim lengths, and bounded on-demand chart series. Exact starts, ends, jump positions, and breadcrumb traces require Activity locations. Saved-route summaries exclude bounds and geometry; those require Saved-route locations and geometry. The two location permissions are independent. Place-name searches send the location text to Mapbox; direct-coordinate searches do not. You can review or disconnect a client at any time. Existing clients must reconnect to gain either new location permission.
